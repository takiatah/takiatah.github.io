  • CSS3

  • Flexbox
  • CSS Animations
  • Google Fonts

Responsive design
The layout adapts across desktop, tablet, and mobile screens using CSS Grid and Flexbox.
Layout and typography
Elegant serif typography for headings pairs with a clean sans-serif for body text.

Figma ConceptConcept / prototype

Synergy

AI fitness app concept

A concept for an AI-assisted fitness application, designed in Figma. This is a prototype, not a deployed product.

  • Figma
  • UI design
  • Prototyping
Concept overview
Synergy explores how an AI coach could personalize workouts and track progress in a friendly mobile interface.
Key screens
Onboarding, a personalized dashboard, workout sessions, and progress tracking.
Visual system
A consistent set of colors, type styles, and reusable components defined in Figma.
User flow
Sign up, set goals, receive a suggested plan, complete sessions, and review progress.
Design rationale
Reduce friction for beginners by turning goals into a clear, guided plan.
