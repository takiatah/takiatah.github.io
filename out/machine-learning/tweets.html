Natural Language Processing with Disaster Tweets

Classifying whether tweets indicate a real disaster or not using Natural Language Processing, TenserFlow, and DistilBERT.

  • Python
  • Pandas
  • scikit-learn
  • TenserFLow
  • DistilBERT
  • Jupyter / Kaggle Notebook
View Source Code(opens GitHub in a new tab)Kaggle Notebook(opens in a new tab)

Problem

The Kaggle NLP Disaster Tweets competition asks for a model that predicts which Tweets are about real disasters and which ones are not. The training set contains 7613 labelled tweets; predictions are submitted for a separate test set of 3263 tweets.

Dataset and features

The notebook uses only one text column as model inputs:

  • text

    Tweet about a potential disaster

Preprocessing

The labelled data is split into a training set and a held-out validation set of 20%, which is used to validate models before predicting on the competition test set.

A DistilBert Preprocessor is loaded using the preset "distil_bert_base_en_uncased" and the sequence_length is shorted to 160 because that is the max length of the tweets. It is then passed into the DistilBert model.

Models

The model used was the DistilBert natural language processing model to get 2 classes: whether the tweets were about diasters or not. A learning rate of 1e-5 was used with an Adam optimizer and 2 epochs.

The model achieved 85% accuracy on the validation set.

What I learned

  • How to plot learning history and compare model configurations using F1-scores.
  • Smaller learning rates around 1e-5 ensure more accurate results.
  • Lower epochs of 2 or 3 are better for training a pre-trained DistilBert model.

Next steps

  • Compare DistilBert with other types sof models.
  • Use cross-validation instead of a single split for more reliable comparisons.
  • Tune hyperparameters systematically rather than fixing them by hand.
